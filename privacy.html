개인정보처리방침

시행일: 2026년 11월 23일

본 개인정보처리방침은 shorts-uploader(이하 "앱")에 적용됩니다. 앱은 운영자 본인의 YouTube 채널에 영상을 업로드하기 위한 개인용 도구입니다.

1. 이용하는 정보

앱은 Google OAuth를 통해 사용자가 승인한 범위 내에서 다음 정보에 접근합니다.

  • YouTube 채널 정보(채널 ID, 채널명)
  • 영상 업로드 권한(youtube.upload)
  • OAuth 액세스 토큰 및 리프레시 토큰

2. 이용 목적

위 정보는 사용자가 지정한 영상을 사용자의 YouTube 채널에 업로드하는 목적으로만 사용합니다. 그 외 광고, 분석, 프로파일링 등의 목적으로는 사용하지 않습니다.

3. 저장 및 보관

OAuth 토큰은 앱이 실행되는 운영자의 로컬 컴퓨터에만 저장되며, 외부 서버로 전송하거나 수집하지 않습니다. 사용자가 권한을 철회하거나 앱 사용을 중단하면 저장된 토큰을 삭제합니다.

4. 제3자 제공

앱은 사용자의 정보를 판매하거나 제3자에게 제공·공유하지 않습니다. 영상 업로드를 위해 Google(YouTube) API에만 데이터를 전송합니다.

5. YouTube API 서비스 및 Google 정책

앱은 YouTube API 서비스를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

앱이 Google API로부터 받은 정보의 사용 및 전송은 제한된 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 권한 철회

사용자는 언제든지 Google 보안 설정 페이지에서 앱의 접근 권한을 철회할 수 있습니다.

Privacy Policy

Effective date: November 23, 2026

This Privacy Policy applies to shorts-uploader (the "App"). The App is a personal tool for uploading videos to the operator's own YouTube channels.

1. Information We Access

Through Google OAuth, and only within the scopes the user grants, the App accesses:

  • YouTube channel information (channel ID, channel name)
  • Video upload permission (youtube.upload)
  • OAuth access and refresh tokens

2. How We Use Information

This information is used solely to upload videos specified by the user to the user's YouTube channel. It is not used for advertising, analytics, or profiling.

3. Storage and Retention

OAuth tokens are stored only on the operator's local computer where the App runs. They are not transmitted to or collected on any external server. Stored tokens are deleted when the user revokes access or stops using the App.

4. Sharing

The App does not sell, share, or disclose user data to any third party. Data is sent only to Google (YouTube) APIs for the purpose of uploading videos.

5. YouTube API Services and Google Policies

The App uses YouTube API Services. By using the App, you agree to the YouTube Terms of Service. Google's handling of your data is governed by the Google Privacy Policy.

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking Access

You can revoke the App's access at any time via the Google security settings page.
