shorts-uploader

YouTube 쇼츠 업로드 도구 / YouTube Shorts Upload Tool

서비스 소개

shorts-uploader는 운영자가 직접 제작한 영상을 운영자 본인의 YouTube 채널에 업로드하기 위한 개인용 도구입니다. YouTube Data API v3를 사용하며, 사용자가 Google 계정으로 로그인하여 권한을 승인한 채널에만 영상을 업로드합니다.

About

shorts-uploader is a personal tool that uploads videos created by the operator to the operator's own YouTube channels. It uses the YouTube Data API v3 and uploads only to channels whose owners have signed in with their Google account and granted permission.

주요 기능 / Features

  • YouTube 채널에 영상(쇼츠) 업로드 / Upload videos (Shorts) to a YouTube channel
  • 영상 제목, 설명, 태그, 공개 설정 지정 / Set title, description, tags, and privacy status

YouTube API 사용 / Use of YouTube API Services

이 앱은 YouTube API 서비스를 사용합니다. 이 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주됩니다.
